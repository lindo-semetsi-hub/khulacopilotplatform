# FieldLink

A static frontend concept for a connected agriculture marketplace, designed for farmers, suppliers, produce buyers, and company administrators.

## Run locally

Open `index.html` in a browser. The page uses plain HTML, CSS, and JavaScript; no build step or backend is required. Google Fonts and the landing image load from external URLs when online.

## Demo interactions

- Switch between farmer, supplier, buyer, and company admin views.
- Preview Basic, Premium, and Enterprise feature access.
- Filter data bundles and complete a mock purchase with the demo wallet.
- Try the wallet controls, loyalty panel, and farming assistant prompt.

Purchases, weather, wallet actions, and assistant responses are frontend demonstrations only. Production use will need the appropriate telco, payment, weather, AI, and account services.
